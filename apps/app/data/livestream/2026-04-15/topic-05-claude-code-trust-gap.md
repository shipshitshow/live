Claude Code is still one of the strongest tools in the market, but the mood around it has changed. The story this week isn’t pure hype. It’s power users comparing hours burned, usage limits, and whether Anthropic is drifting into the same trust problems people already hate in ChatGPT.

## Hot Take

Anthropic’s risk is not that Claude Code gets beaten on raw quality. It’s that trust erodes at the product layer while everyone else catches up on capability. If users start thinking “best model, annoying workflow,” that’s how a category leader fumbles the bag.
